## BLEND / SMUDGE TOOL

**MISSING entirely.** Requires: sampling rendered color under pen (needs a
readback of the composed layer), carried-color mixing (80/20), soft radial
stamps stored as vector data (position, radius, color, alpha), strength/
size/softness controls, pressure->strength.

## LAZY BRUSH (stabilizer)

**MISSING entirely.** Current `StrokeSmoother` is only a min-distance filter.
Spec requires: rope-following brush point with lazy radius 0-200 SCREEN px,
pen->brush guide line + circle overlay, quadratic curve smoothing, tapered
stroke ends.

## SHAPES

**MISSING entirely.** No parametric shapes (line, rect, rounded rect,
ellipse, triangle, polygon, star, arrow), no live preview, no fill/outline
options, no constrain/from-center toggles, no tap-a-shape select with corner

## Refactor plan (phased)

**P0 — Nested zoom levels (foundation, blocks everything)**
New `ZoomLevel` model: tree of levels; child origin = zoom focus point,
child scale-to-parent = threshold (e.g. 100). Every stroke/shape/stamp/image
is stored in the level where it was created, in that level's local floats.
Camera becomes (level, local zoom, local pan). Rendering draws the current
level plus parent chain and child chain at correct relative scales. Crossing
the threshold promotes/demotes the camera to a child/parent level. Codec
migrates to per-level storage. All camera/transform tests rewritten. Target:
30+ levels, no jitter, zoom-out shows earlier levels intact.

**P1 — Spec-correctness fixes**
Screen-relative brush size (convert to level units at commit); stylus-vs-
finger input routing; pencil pressure->opacity.

**P2 — Layers v2**: duplicate, rename, drag-reorder, lock (draw + select
protection), blend modes (Android `BlendMode` API 29+, normal fallback),
collapsible panel.

**P3 — New tools**: shapes (parametric data + live preview + constrain/from-
center + handles), lazy brush (rope model + overlay + quadratic smoothing +
taper), blend/smudge (sampled-color carry + vector stamps).

**P4 — Image v2 + UI**: image own-layer + transform handles + transparency +
lock + tracing mode + grayscale/contrast; toolbar sections; zoom readout;
demo button; bitmap-blur note.

## Open question
The guidelines are written in web-platform idioms (`touch-action: none`,
`devicePixelRatio`, `accept="image/*"` file inputs, radial-gradient stamps).
Decision required: implement natively in the existing Android/Kotlin app, or
build the spec as a web (HTML5 Canvas) app.
